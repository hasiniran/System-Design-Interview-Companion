# Playbook 03 Practice

## Exercise 1

Estimate storage.

Users: 2 million

Daily uploads per user: 3

Average file size: 2 MB

Calculate:

- Uploads/day
- Storage/day
- Storage/year

---

## Exercise 2

Estimate QPS.

Assume:

- 20 million DAU
- 15 requests per user per day

Calculate:

- Requests/day
- Average QPS
- Peak QPS (5× average)

---

## Exercise 3

Estimate bandwidth.

Average response size: 500 KB

Peak QPS: 4,000

Estimate:

- MB/sec
- GB/hour
