# System Design Interview Companion

> The guide I wish I had when preparing for backend system design interviews.

This repository is a concise, interview-focused reference for software engineers preparing for backend and distributed systems interviews.

Unlike traditional textbooks, this guide emphasizes:

- Why a technology exists
- When to use it
- When not to use it
- Trade-offs
- Common interview questions
- Whiteboard-friendly explanations
- Java/Spring notes
- AWS mappings

Each topic is designed to be read in under 10 minutes.
